## About

GroceryNotes is a mobile app that turns recipe links into organized grocery lists. Paste a YouTube cooking video URL, and AI extracts all the ingredients for you. Manage daily shopping notes, track items, and discover new recipes.

>AI-powered grocery list generator from recipe links

## Tech Stack

| Layer            | Technology                       |
| ---------------- | -------------------------------- |
| Framework        | Flutter 3.x (Dart ^3.11.5)       |
| State Management | Riverpod with code generation    |
| AI Backend       | Vercel Serverless + Gemini AI    |
| Authentication   | Firebase Auth + Google Sign-In   |
| Database         | Cloud Firestore                  |
| Local Storage    | Hive (planned)                   |
| External APIs    | YouTube Data API v3, TheMealDB   |
| Design System    | Custom tokens, Plus Jakarta Sans |

## Features

- **AI Recipe Extraction** - Paste a YouTube/TikTok/Instagram link and get a structured ingredient list powered by AI
- **Grocery List Management** - Search, categorize, swipe-to-delete, and manually add items
- **Ingredient Spotlight** - Discover new ingredients with images
- **Daily Notes** - Track your daily shopping with progress indicators
- **Custom Design System** - Dark theme with animated orb background and smooth transitions
